# TDA Academy · Algoritmos y Estructuras de Datos (UADE)

Plataforma web interactiva para el aprendizaje riguroso de Tipos de Datos Abstractos (TDAs), análisis de complejidad computacional (Big-O) y resolución de exámenes prácticos de Programación 2 (Cátedra UADE).

## Contenido

- **Módulo 00:** Mindset, Contrato de Interfaces y Preservación de Memoria Heap
- **Módulo 01:** Pilas (`PilaTDA` - LIFO) · Comparativa $O(1)$ vs $O(n)$ (`PilaTF`, `PilaTI`, `PilaTF2`, `PilaLD`)
- **Módulo 02:** Colas (`ColaTDA` - FIFO) y Colas con Prioridad (`ColaPrioridadTDA`)
- **Módulo 03:** Estructuras Dinámicas y Punteros (`Nodo` en RAM)
- **Módulo 04:** Conjuntos (`ConjuntoTDA`) y Diccionarios (`DiccionarioSimpleTDA` y `DiccionarioMultipleTDA`)
- **Módulo 05:** Árboles Binarios de Búsqueda (`ABBTDA`), Recorridos (Pre/In/Postorden), AVL y Árboles B
- **Módulo 06:** Grafos (`GrafoTDA`), Matriz vs Lista de Adyacencia, Recorridos BFS y DFS
- **Módulo 07:** Matriz Maestra de Costos Asintóticos Big-O
- **Módulo 08:** Sandbox Interactivo con Memoria Interna
- **Módulo 09:** Simulador Paso a Paso con Memoria RAM Visual
- **Módulo 10:** Banco de Exámenes Reales de Cátedra UADE

## Estructura de Práctica en cada Módulo

1. **Pilar 1 (Web Interactivo):** Lectura de código, traza de memoria y cálculo de orden de complejidad Big-O temporal y espacial con retroalimentación inmediata.
2. **Pilar 2 (Para tu IDE):** Misión de parcial con explicación pedagógica profunda ("nivel dios"), analogía del mundo real, especificación rigurosa de firma Java, trampas de examen, traza de escritorio paso a paso, y plantilla Java autocontenida lista para copiar y ejecutar en IntelliJ / Eclipse / VS Code.
